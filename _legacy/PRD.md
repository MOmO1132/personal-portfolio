# 个人作品集网站 PRD

版本：v1.0（2026-10-24）
状态：已确认，进入开发

---

## 1. 背景与目标

搭建一个属于自己的个人作品集网站，用于集中展示个人介绍、技能与项目成果，可作为求职、课程作业、社交分享的统一入口。

**本期目标（v1）：**
- 上线一个设计现代、动效流畅、移动端友好的单页作品集网站
- 内容暂时使用占位素材，架构上保证后续替换真实资料时**零改代码**
- 代码结构支持后续迭代（加栏目、换主题、加博客、加英文版）时不需要推翻重写

**明确不做（本期）：**
- 后端、数据库、评论、访问量统计
- 博客/文章系统（架构预留，v2 再议）

---

## 2. 需求研究结论

调研了 2026 年前后的作品集网站案例与设计趋势，提炼出以下共识（详见文末参考链接）：

1. **首屏即名片**：大标题 + 一句话定位 + 明确的行动按钮（CTA），3 秒内说清楚"你是谁、能做什么"。
2. **成果量化**：首屏用数字说话（项目数、年限、技能数），比形容词更有说服力。
3. **项目卡片化**：项目以卡片呈现（封面图 + 简述 + 技术栈标签 + 链接），支持分类筛选，优先展示最强项目。
4. **深色主题是主流**：开发者作品集普遍采用深色主题 + 单一强调色/渐变色，显得专业且聚焦内容。
5. **微交互是质感来源**：滚动渐入、悬停放大、数字滚动、打字机轮播等细节，决定网站是"模板感"还是"定制感"。
6. **必备体验细节**：吸顶导航 + 滚动高亮当前栏目、返回顶部、移动端汉堡菜单、减少动画偏好适配（accessibility）。

## 3. 核心功能

### 3.1 首页（Hero）
- 大标题（姓名 + 轮播定位语，打字机效果）
- 个人简介一段话
- 头像（带装饰性渐变光环）
- 行动按钮：查看项目 / 联系我 / 下载简历（链接可后补）
- 数据概览：项目数、学习/工作年限、技能数（数字滚动动画）
- 社交入口：GitHub、邮箱等图标链接

### 3.2 关于我（About）
- 详细介绍（多段落）
- 技能列表：进度条形式，带等级动画
- 工具/技术标签云（平铺标签，便于快速扫读）

### 3.3 项目展示（Projects）
- 项目卡片列表，每张卡片包含：项目名称、封面截图、简短描述、技术栈标签、演示链接、源码链接
- 支持一个"精选项目"大卡 + 常规卡片网格混排
- 按分类筛选（按钮式过滤器，全部/数据分析/Web 开发等）
- 悬停效果：封面图微放大、卡片浮起

### 3.4 联系方式（Contact）
- 邮箱（一键复制按钮，带复制成功反馈）
- GitHub、社交媒体链接
- 明确的行动号召文案

### 3.5 全局
- 吸顶导航栏：滚动时毛玻璃背景，当前栏目高亮（scroll spy），移动端折叠为汉堡菜单
- 深色/浅色主题切换（默认深色，偏好记忆在 localStorage）
- 滚动渐入动画（IntersectionObserver 实现）
- 返回顶部按钮
- 页脚：版权信息 + 社交链接

## 4. 设计要求

| 项目 | 要求 |
| --- | --- |
| 整体风格 | 深色近黑底 + 单一荧光强调色，简洁专业；首屏为横版一屏构图（顶部信息行 / 左侧大标题+简介+按钮 / 右侧照片 / 底部数据行），对照参考设计 |
| 排版 | 展示字体 + 中文无衬线 + 等宽字体标注（编号、标签、数据），标题醒目但克制 |
| 布局密度 | 紧凑：首屏一屏呈现核心信息，栏目间距收敛，内容区最大宽度 1240px 居中 |
| 动效 | 首屏标题遮罩上浮、滚动渐入、数字滚动、悬停微交互，全部克制不花哨 |
| 响应式 | 断点 ≥1024 / ≥860 / ≥640 三档，手机端单列布局 |
| 无障碍 | 语义化标签、alt 文本、focus 样式、prefers-reduced-motion 降级 |
| 性能 | 无重型框架，首屏零依赖外网资源也能渲染（字体走系统回退） |

## 5. 非功能需求（扩展性，本次重点）

1. **内容驱动架构**：所有文案、图片路径、链接集中在 `assets/js/content.js` 一个配置对象里，替换个人资料 = 只改这一个文件，不改任何 HTML/CSS/JS 逻辑。
2. **主题系统**：颜色全部走 CSS 变量，新增主题 = 加一套变量 + 一行 data 属性，不用改组件样式。
3. **栏目模块化**：每个栏目是一个独立的渲染函数，新增栏目 = content.js 加数据 + main.js 加一个函数 + 导航加一项。
4. **双语就绪**：文案按"一个 key 一段文本"组织，未来加英文版只需把字符串换成字典结构。
5. **零构建**：纯静态 HTML/CSS/JS，不需要 Node、不需要打包器，任何电脑双击 index.html 就能看，任何静态托管（GitHub Pages 等）都能直接部署。

## 6. 内容占位说明

以下资料后续由用户提供后替换进 `content.js`：

- 真实姓名、定位语（1-3 个角色标签）
- 个人简介文案（首屏一句 + 关于我段落）
- 头像照片
- 项目清单（名称、描述、截图、技术栈、链接，建议 3-6 个）
- 联系方式（邮箱、GitHub、其他社交账号）
